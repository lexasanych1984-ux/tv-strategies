## Как считались нестандартные столбцы

- **R** — `P&L / (депозит на входе × 2%)`; депозит восстановлен компаундом от $10 000 внутри окна.
- **MFE в R** — максимальный ход в плюс между входом и выходом по барам M15 того же окна,
  делённый на риск сделки.
- **Глубина захода в POI** — доля пройденной FVG-зоны: `(верх зоны − стоп) / высота зоны`.
  Стоп = `LsweepLow`, то есть самая глубокая точка свипа. Зона восстановлена оффлайн из 4H-баров
  по логике ветки `snapshot`. **Самый ненадёжный столбец:** у 21 сделки из 64 FVG восстановить
  не удалось (метка «н/д») — там сетап взводился по ордерблоку или свипу фрактала, а не по FVG.
- **D1-биас** — `close` последней закрытой дневки против EMA(20) D1. Собственного `dailyBias`
  в коде нет, проверено грепом.
- **До PDH/PDL** — расстояние от входа до High/Low предыдущего дня в направлении сделки, в R.

Распределение бимодально: сделка либо умирает не дойдя до 2R (34 штуки), либо доезжает до
полного 3R (22 штуки). Промежуточной популяции, которую спасал бы более близкий тейк,
практически нет.

### Цена вопроса для тейка по ликвидности

| | |
|---|---|
| Спасаемые сделки (MFE ≥ 2R, не TP) | 8 шт, сейчас дают +7.5R → при тейке 2R дали бы +16.0R |
| **Выигрыш** | **+8.5R за 5 лет** |
| Сделки, доехавшие до 3R | 22 шт, дают +65.7R → при тейке 2R дали бы +44.0R |
| **Потеря** | **−21.7R за 5 лет** |

Для плоского тейка 2R баланс **−13.2R**. Тейк по ликвидности — не плоский 2R, он может стоять
и дальше 3R, но он ограничен сверху положением пула.

### Где стоят пулы на самом деле

| Расстояние до встречного PDH/PDL | Сделок | Доля |
|---|---|---|
| < 1R | 43 | **67%** |
| 1–2R | 19 | 30% |
| 2–3R | 1 | 1.5% |
| ≥ 3R | 1 | 1.5% |

Правило из ТЗ — «ближайший пул < `minTpR` → не входить». При `minTpR = 2.0` под него подпадает
всё, что ближе 2R, то есть **62 сделки из 64 (97%)**. Даже если ограничиться только самой
грубой группой «ближе 1R», отсекается 67% входов — вчетверо больше порога в 30%,
после которого вы просили отметить это отдельно.

Оценка **консервативная**: посчитан только PDH/PDL предыдущего дня. Приоритетная цепочка из ТЗ
(PDH/PDL → экстремум 4H-свинга → недельный H/L) добавляет кандидатов, а ближайший из большего
набора уровней может стать только ближе. То есть реальная доля отсечённых будет не ниже.

Единственный кластер убытков, который держится на данных, — **тесный стоп (20–30 пипсов),

**Для Шага 2 данные скорее отрицательные.** Пул «недоехавших» сделок, ради которых задумывался
тейк по ликвидности, составляет 8 сделок из 64 и стоит максимум +8.5R за пять лет, тогда как
22 сделки, регулярно доезжающие до полного 3R, от переноса тейка ближе теряют больше. Плюс
ближайший встречный пул у двух третей входов лежит ближе 1R, то есть порог `minTpR = 2.0`
превратится в фильтр, режущий большинство сделок, — что само по себе будет уже не A/B тейка,
а A/B фильтра входов.

## Развилка по критериям п.3 ТЗ

- ATR-шкала исходы **не** делит лучше → ветка «A/B ATR-коридора» отпадает.
- Монотонность есть, относительный разрыв равномерен по окнам (6/6) → ветка «архив +
  портфельное расширение» тоже отпадает.
- Остаётся **A/B поднятия пола стопа**.

**Цена вопроса, посчитанная заранее:** пол в 30 пипсов срежет 24 входа из 64 (**38%**),
а их суммарный вклад составляет −2.47R из общих +39.23R. То есть выигрыш в сумме
всего **≈ +2.5R за 5 лет**: экспектанси на сделку вырастет с +0.613R до ~+1.04R, но общий
результат почти не изменится, потому что отсекаемая группа в агрегате около нуля,
а не глубоко убыточна.

Выигрыш здесь — в дисперсии и КПД (на 38% меньше сделок за тот же результат), а не в прибыли.
Это стоит учесть при постановке критериев A/B: по ΣR разница будет в пределах шума,
показательными будут экспектанси, PF и просадка.
