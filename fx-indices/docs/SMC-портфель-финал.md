## Общая механика (одинакова для всех потоков)

1. **Контекст (старший ТФ):** структура по фракталам (плечо 2). BOS = закрытие свечи старшего ТФ за последним фракталом.
2. После BOS фиксируется **зона интереса (POI)** — любая из: FVG импульса, ордерблок, уровень свипнутого фрактала контекста.
3. Сетап живёт 42 бара контекста. Отмена: обратный BOS, истечение времени, закрытие за инвалидацией (фрактал ± 0.5 ATR).
4. **Вход (младший ТФ):** цена возвращается в POI → свип фрактала младшего ТФ (тень за экстремум, закрытие обратно) → слом структуры закрытием свечи → вход по рынку.
5. **Стоп:** за экстремум свипа. **Тейк:** фиксированный 3R сразу. Без безубытка, частичных и переносов. Одна позиция на поток.

## Фильтры (сигнал отменяется, не переносится)

- **Сессии:** вход только в часы Лондона (08–17 по Лондону) или Нью-Йорка (08–17 по НЙ).
- **Новости:** запрет входа ±30 мин вокруг NFP, CPI США, решений и прессконференций FOMC и ЕЦБ.
- **Стоп-коридор** (свой на каждый поток, см. ниже): слишком узкий стоп = шум, слишком широкий = перерастянутое движение.

## Механика Asia Sweep (кратко)

H4-зона интереса (FVG / OB / RB / свип, автодетект) задаёт направление → после закрытия Азии (для US-версии — ночи Globex) ждём свип её экстремума по направлению зоны → вход по закрепу тела за пост-свиповой проторговкой → стоп за точку свипа, тейк на противоположном краю Азии, мин. RR 1:1. Фильтры: новости ±30м, зона ≤1×ATR(H4), окно входа 3 часа. 10 попыток улучшения бейзлайна отвергнуты A/B (тренд-фильтры, ATR-режимы, ширина Азии, скип NFP-дней и др.).
